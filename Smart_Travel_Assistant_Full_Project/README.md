# Smart Travel Assistant (STA)

## AI Coursework 2 — Explainable Travel Recommendation System

Smart Travel Assistant (STA) is a classical Explainable Artificial Intelligence (XAI) system developed for an Artificial Intelligence coursework project.

The project combines:
- Rule-based reasoning
- Bayesian probabilistic scoring
- Explainable AI (XAI)
- Intent classification
- Fuzzy matching
- Knowledge-based systems

to create a transparent and auditable travel recommendation system.

---

# Features

- Explainable recommendation engine
- Bayesian destination scoring
- Intent classification system
- Fuzzy activity matching
- Rule-based expert system
- Safety and transport information
- Recommendation explanations
- Edge-case handling
